# ⚙️ Jack's Server Side Tweaks v2

Provides a suite of server-side tweaks and survival-friendly tools to the game.

## Features

All features can be disabled individually, and are highly configurable. For more details, see the [wiki](https://docs.jackf.red/jsst).

<details>
<summary>🗺️ Map Editor</summary>

![A player removing, changing and renaming icons on a map in-game.](https://i.imgur.com/wRqwQ0r.gif)

An in-game map editor, accessible by placing a map in an item frame and right clicking with a feather. You can add, rotate and add labels to a variety of icons, and easily remove them after.

</details>

<details>
<summary>🔤 Banner Writer</summary>

![A player quickly writing text on banners.](https://i.imgur.com/hlzMuqH.gif)

A command to generate text on banners. Works in survival, as long as you have enough banners in your hand.

</details>

<details>
<summary>🚨 Beacon Enhancement</summary>

![An example of the remade beacon GUI, supporting a max tier of 6 and custom powers.](https://i.imgur.com/TjkA2vM.png)

Adds the ability to customize the beacon's primary and secondary power set, as well as increasing the maximum level to 6. All features are fully configurable.

</details>

<details>
<summary>🔥 Campfire Timers</summary>

![Progress percentages above a campfire.](https://i.imgur.com/MoI2fLY.gif)

Adds a progress bar above cooking campfire items.

</details>

<details>
<summary>💡 Extra Highlights</summary>

![Dropped sugarcane being highlighted through blocks.](https://i.imgur.com/YF4wuq6.png)

![Hidden logs being shown.](https://i.imgur.com/rSzP1nS.png)

Sugarcane, when held in hand, will now highlight nearby dropped sugarcane items; useful for dense farms.

Players can also sneak-right click with an axe to find logs hidden in leaves.

</details>

<details>
<summary>🫵 Item Nudging</summary>

![Items moving up and towards the player.](https://i.imgur.com/OeEuFVc.gif)

Mined items will now aim towards the player when mined, and will always gain enough height to be picked up from above. Especially useful for Skyblock; you'll notice it pretty quick.

</details>

<details>
<summary>🎄 Sapling Replanting</summary>

![Saplings replanting themselves.](https://i.imgur.com/UHahk91.gif)

Sapling items, upon decaying, will now try to replant themselves nearby. They give eachother space and will group together for 2x2 saplings.

</details>

<details>
<summary>❓ Other features</summary>

There are also a handful of other features not easily shown:

- Portable Crafting: Use crafting tables from the inventory,
- Effector Ranges: Adjust the range of active Beacons and Conduits,
- Item Editor: WIP, adds an exstensive server-side item editor GUI.

</details>

# 🛠️ Install & Requirements

Works both in single players worlds, and server-side only. **JSST** is fine to add to existing worlds, but removing it will cause some custom map decorations and beacon powers to reset.

**JSST** requires [Fabric API](https://modrinth.com/mod/fabric-api) and [YACL](https://modrinth.com/mod/yacl).
