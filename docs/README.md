# Jack's Server Side Tweaks

**JSST** is a server-side mod that adds several quality-of-life tweaks and tools to Minecraft.

{% hint style="info" %}
This documentation is for version 2 of JSST only.
{% endhint %}

## Tweaks

* [beacon-enhancement.md](tweaks/beacon-enhancement.md "mention") - Fully customise the Beacon.
* [campfire-timers.md](tweaks/campfire-timers.md "mention") - Adds progress timers above campfires.
* [effector-ranges.md](tweaks/effector-ranges.md "mention") - Modify the range of Beacons and Conduits.
* [extra-highlights.md](tweaks/extra-highlights.md "mention") - QOL highlights for tree logs and sugarcane.
* [item-nudging.md](tweaks/item-nudging.md "mention") - Changes to dropped item movement to make them far nicer.
* [portable-crafting.md](tweaks/portable-crafting.md "mention") - Use a crafting table from the inventory.
* [sapling-replant.md](tweaks/sapling-replant.md "mention") - Saplings now replant themselves if able.

## Tools

* [banner-writer.md](tools/banner-writer.md "mention") - Easily write text on banners.
* [item-editor.md](tools/item-editor.md "mention") - Extensible item editing GUI with a survival-friendly mode for cosmetic changes.
* [map-editor.md](tools/map-editor.md "mention") - Add icons, arrows and labels to maps using a feather.
