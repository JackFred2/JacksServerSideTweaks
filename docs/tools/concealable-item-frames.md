# Concealable Item Frames

**JSST** adds the ability for players to toggle the invisibility of item frames, by right clicking with any potion of invisibility.

<figure><img src="../.gitbook/assets/concealable_frames.png" alt=""><figcaption><p>An example of an Item Frame and Glowing Item Frame being invisible.</p></figcaption></figure>

## Configuration

### Enabled

Whether this feature should be enabled or not.

* Options: `true`, `false`
* Default: `true`

### Show Empty Particles

<figure><img src="../.gitbook/assets/java_TiaLNpx4DX.png" alt=""><figcaption><p>Example of the empty particles</p></figcaption></figure>

Whether to occasionally show particles where there are empty and invisible item frames.

* Options: `true`, `false`
* Default: `true`
