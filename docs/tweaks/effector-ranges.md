# Effector Ranges

**JSST** allows you to configure the maximum ranges of Beacons and Conduits.

## Configuration

### Beacon Range Modifier

Multiplier for the maximum range of an active beacon.

* Options: `[50%, 500%]`
* Default: `150%`

### Conduit Range Modifier

Multiplier for the maximum range of an active conduit.

* Options: `[50%, 500%]`
* Default: `150%`
