# Campfire Timers

Items cooking in a campfire will now show progress text above each item.

<figure><img src="../.gitbook/assets/campfire_timers.gif" alt=""><figcaption><p>Progress percentages increasing above cooking items.</p></figcaption></figure>

## Configuration

### Enabled

Whether this feature should be enabled or not.

* Options: `true`, `false`
* Default: `true`
