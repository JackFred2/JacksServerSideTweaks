# Installation Requirements

**JSST** has the following dependencies:

* [Fabric API](https://modrinth.com/mod/fabric-api)
* [YACL](https://modrinth.com/mod/yacl)
* [Mod Menu](https://modrinth.com/mod/modmenu) (or an alternative like Catalogue; not strictly required but needed to access the config screen).

## Guide

Place JSST and it's dependencies in your mods folder. Access the config screen through Mod Menu.

JSST should be safe to remove or add to existing worlds, but some persistence features will fail on removal:

* Map Decorations (Map Editor)
* Beacon Powers outside the vanilla set
